## 🚀 Flagship Project — FraudGuard AI

<div align="center">

> **The problem:** 95,000+ UPI fraud cases. ₹1,000+ Crore lost. Victims frozen — not knowing what to do.
>
> **The solution:** A 3-agent AI system that activates the moment fraud is reported.

</div>

```
┌─────────────────────────────────────────────────────────────────────┐
│                      FRAUDGUARD AI PIPELINE                         │
│                                                                     │
│  [ Victim Input ]                                                   │
│         │                                                           │
│         ▼                                                           │
│  🔍 Fraud Analyzer  ──▶  fraud type · severity · recovery score    │
│         │                                                           │
│         ▼                                                           │
│  ⚡ Negotiation Agent ──▶  60-sec checklist · bank complaint       │
│         │                                                           │
│         ▼                                                           │
│  🕸️  Trace Agent    ──▶  money flow graph · freezable nodes        │
│                                                                     │
│  Stack: Claude (Anthropic) · Vanilla JS · HTML5 Canvas · jsPDF     │
└─────────────────────────────────────────────────────────────────────┘
```
