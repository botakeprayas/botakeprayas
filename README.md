## 🚀 Featured Projects

### 🏗️ INTeLLISeNZ — Structural Health Monitoring
`🟡 In development`

A structural health monitoring system that analyses sensor data from structures such as bridges, buildings, tunnels, and retaining walls.

- Sensor time-series cleaning and feature engineering
- Anomaly detection and forecasting with ML and DL models
- Storage in PostgreSQL and TimescaleDB
- API integration and dashboard development
- Model evaluation and MLOps workflows

### 🕹️ Live Motion Sensor Classification
`🟢 Working prototype`

A real-time motion classifier built on an **MPU6050** accelerometer and gyroscope. An Arduino streams readings over serial, Python runs live inference, and Streamlit visualises the predicted motion.

![Arduino](https://img.shields.io/badge/Arduino-00879E?style=flat-square&logo=arduino&logoColor=white) ![Python](https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white) ![Scikit-learn](https://img.shields.io/badge/Scikit--learn-F7931E?style=flat-square&logo=scikitlearn&logoColor=white) ![Streamlit](https://img.shields.io/badge/Streamlit-FF4B4B?style=flat-square&logo=streamlit&logoColor=white)
